Globe - offline pack
1. Install Node 18+ once (Ubuntu: sudo apt install nodejs). No internet is needed after that.
2. Run:  bash start.sh        (Windows: start.bat)
3. Open http://localhost:8765 in the browser (Chrome/Firefox). Press the clicker or click the globe.
Music: browsers need one click/key press before sound, unless autoplay is allowed for localhost
(Firefox: Settings > Privacy & Security > Permissions > Autoplay > Settings, add http://localhost:8765 = Allow Audio and Video).
Satellites on the globe use cached data only; Singapore live weather/traffic is hidden/offline-safe.
